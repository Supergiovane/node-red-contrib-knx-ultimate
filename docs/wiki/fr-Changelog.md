# Notes de version

## 8.0.0

- Reliez Node-RED à votre installation KNX. La version 8 comprend six nœuds KNX et une configuration de passerelle partagée.
- Installez ces packages séparés selon vos besoins. HUE Ultimate et Matter Ultimate utilisent les messages Node-RED habituels. Vous pouvez aussi les utiliser avec KNX Ultimate : sélectionnez la passerelle KNX existante pour activer l’intégration native.
- Vous utilisez déjà la version 7 ? Convertissez les anciens nœuds et faites Deploy avant d’installer la version 8.
