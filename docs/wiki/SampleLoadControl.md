# Load Control - Manual Shedding Mode

Import the JSON through **Node-RED → Import**. Select your own gateway and replace sample addresses with addresses from your ETS project before Deploy. Read the Comment nodes for the setup required by each example.

These files come from the package’s examples folder. The utility examples use KNX Utility, not the removed separate nodes.
