# Novedades de las versiones

## 8.0.0

- Conecta Node-RED a tu instalación KNX. La versión 8 incluye seis nodos KNX y una configuración de gateway compartida.
- Instala estos paquetes separados cuando los necesites. HUE Ultimate y Matter Ultimate trabajan con mensajes normales de Node-RED. También puedes usarlos con KNX Ultimate: selecciona el gateway KNX existente para activar la integración nativa.
- ¿Ya usas la versión 7? Convierte los nodos antiguos y haz Deploy antes de instalar la versión 8.
