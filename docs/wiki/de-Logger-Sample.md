# Logger ETS File and Telegram Count

Importiere die JSON-Datei über **Node-RED → Importieren**. Wähle dein Gateway und ersetze die Beispieladressen vor Deploy durch Adressen aus deinem ETS-Projekt. Lies die Comment-Knoten für die nötige Einrichtung.

Die Dateien stammen aus dem examples-Ordner des Pakets. Die Utility-Beispiele verwenden KNX Utility statt der entfernten separaten Knoten.
