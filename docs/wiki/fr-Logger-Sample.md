# Logger ETS File and Telegram Count

Importez le JSON via **Node-RED → Importer**. Sélectionnez votre passerelle et remplacez les adresses d’exemple par celles du projet ETS avant Deploy. Lisez les nœuds Comment pour les réglages propres à chaque exemple.

Ces fichiers proviennent du dossier examples du package. Les exemples Utility utilisent KNX Utility, pas les anciens nœuds séparés.
