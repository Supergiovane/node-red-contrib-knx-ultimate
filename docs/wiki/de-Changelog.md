# Versionshinweise

## 8.0.0

- Verbinde Node-RED mit deiner KNX-Anlage. Version 8 enthält sechs KNX-Knoten und eine gemeinsame Gateway-Konfiguration.
- Installiere diese separaten Pakete bei Bedarf. HUE Ultimate und Matter Ultimate arbeiten mit normalen Node-RED-Nachrichten. Du kannst sie auch mit KNX Ultimate verwenden: Wähle das vorhandene KNX-Gateway für die native Integration.
- Du nutzt bereits Version 7? Konvertiere die alten Knoten und führe ein Deploy aus, bevor du Version 8 installierst.
