# Novità delle versioni

## 8.0.0

- Collega Node-RED al tuo impianto KNX. La versione 8 include sei nodi KNX e una configurazione gateway condivisa.
- Installa questi package separati quando ti servono. HUE Ultimate e Matter Ultimate lavorano con i normali messaggi Node-RED. Puoi usarli anche con KNX Ultimate: seleziona il gateway KNX esistente per attivare l’integrazione nativa.
- Usi già la versione 7? Converti i vecchi nodi e fai Deploy prima di installare la versione 8.
